🌟 ¿Qué es MockHive?

              

                MockHive es la plataforma de computación cloud efímera y distribuida de Terra. Convierte el tiempo de computación gratuito de GitHub Actions en servidores virtuales interactivos (HiveNodes), máquinas de estado serverless (Waggles), micro-funciones aisladas (PollenPods) y clusters paralelos Map-Reduce (HiveGrid) sin servidores dedicados ni costes de suscripción.
              

            


            

              
🏰 HiveNodes: Servidores Virtuales con Conexión SSH

              

                Un HiveNode es una máquina virtual Ubuntu completa ejecutada sobre un runner de GitHub Actions. Para conectarte:
              

              
    
                
  • Iniciar Servidor: Haz clic en ⚡ Iniciar Servidor en la tarjeta del nodo. Esto dispara un runner real en GitHub Actions con servidor Tmate.
    • 
                
  • Copiar SSH: Al iniciar, el runner emite una URL SSH dinámica real que puedes copiar directamente a tu terminal.
    • 
                
  • Web Shell: Abre una sesión interactiva en vivo incrustada en el navegador.
    • 
              

            


            

              
⚠️ Modo 24/7 Lazarus Relay & ToS de GitHub

              

                El modo 24/7 utiliza relevos automáticos (relays) antes de las 6 horas de límite del runner de GitHub. Úsalo con moderación y exclusivamente para servidores que realmente requieran continuidad. Para desarrollo y tareas puntuales, utiliza siempre el modo TTL Efímero.
              

            


            

              
🐝 Waggles: Step Functions & Control Humano

              

                Define máquinas de estado declarativas compatibles con estados Task, Choice, Parallel y WaitForCallback. Cuando una ejecución llega a una pausa, puedes revisarla y aprobarla con 1 clic en el panel de Waggles.
              

            


            

              
💡 Buenas y Malas Prácticas

              

                

                  
✔️ Buenas Prácticas

                  
    
                    
  • Monta almacenamiento persistente en /mockhive/data para no perder archivos.
    • 
                    
  • Utiliza Rolla-Balls para datasets grandes de más de 2GB.
    • 
                    
  • Usa PollenPods para tareas que requieran respuestas JSON rápidas en menos de 50ms.
    • 
                  

                

                

                  
❌ Malas Prácticas

                  
    
                    
  • No dejes corriendo múltiples servidores 24/7 sin supervisión.
    • 
                    
  • No guardes contraseñas en texto plano dentro de los init scripts; usa Secrets de GitHub.
    •
